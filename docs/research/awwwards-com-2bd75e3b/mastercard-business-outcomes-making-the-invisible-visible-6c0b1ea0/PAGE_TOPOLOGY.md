# Page Topology

1. **Editorial utility header** — compact nav rail; static on desktop, sticky on mobile in the source. Adapted to `PHOTO SKILL STUDIO`, API state, and Skill install.
2. **Hero / input chapter** — centered date-like eyebrow, oversized two-line title, author-like metadata, then the uploaded photo as the wide visual anchor. Adapted title: `MAKE THE SOURCE VISIBLE` / `01. INPUT PHOTO`.
3. **Narrative lead** — narrow editorial copy that explains the photo-to-style workflow. It is a quiet explanatory block, not a marketing card.
4. **Numbered process chapters** — source article uses `1. Challenge`, `2. Concept`, `3. Look & Feel`, etc. Adapted to `1. SOURCE`, `2. STYLE`, `3. OUTPUT`; each chapter wraps the existing tool controls.
5. **Quote/action band** — source quote is oversized with a left rule. Adapted to a black/red command strip containing the selected Skill count and generation action.
6. **Output archive** — wide framed media area with result cards; empty state mirrors source's image placeholder rhythm.
7. **Quiet utility footer/dialog layer** — source has a multi-column footer. Adapted to install dialog and a compact end rail so the actual Skill library remains accessible.

Interaction model: upload and Skill selection are click/drag-driven; generation is explicit click-driven with parallel requests; result retry/download are per-card click-driven; layout is scroll-driven only through native document flow. No source-site video, 3D, analytics, cookie banner, or external navigation is copied.
