# Page Topology

## Source Topology

1. Thin utility navigation layered over a full-viewport editorial hero.
2. Oversized uppercase title and split-tone hero image.
3. Horizontal collection/product rails with drag affordance.
4. Large black brand interlude with oversized wordmark.
5. Editorial category and campaign image stages.
6. Large quiet off-white areas followed by torn/irregular section transitions.

## Adapted Workspace Topology

1. `AppHeader`: sticky utility rail with bracketed identity, API state, and Skill installation command.
2. `SourceWorkspace`: numbered input section with oversized condensed heading, upload/preview stage, and operational settings rail.
3. `SystemBand`: full-width black status interlude showing model, selected Skill count, and execution mode.
4. `SkillMatrix`: numbered four-column editorial rail of selectable Skill items.
5. `ActionBar`: high-contrast generation command that exposes selected count.
6. `ResultsGallery`: numbered output section using a two-column editorial image grid.
7. `InstallDialog`: declarative Skill package installation surface.

All topology remains on the existing `/` route. No backend or API route changes are required.
